# 设计文档：项目 README

## 背景

项目准备开源，需要一个面向终端用户的专业 README 文档。当前 README 只有一行简介，无法有效展示项目价值和引导用户使用。

## 目标

- 让用户快速了解项目功能和价值
- 提供清晰的 Docker 部署指引
- 展示项目界面和核心功能
- 符合开源项目标准格式

## 设计方案

### README 结构

```
1. 项目简介
   - 一句话描述
   - 功能亮点列表（6-8 个要点）

2. 截图展示
   - 订阅管理页面
   - Mihomo 实例管理页面
   - 转发路径可视化页面
   - 使用占位图，后续替换为真实截图

3. 快速开始
   - Docker Compose 一键部署
   - 默认端口和访问地址
   - 首次使用引导

4. 配置说明
   - 环境变量配置
   - 数据目录说明
   - 端口配置

5. 架构概览
   - 简化的架构图（文字版）
   - 模块说明（简要）

6. 常见问题
   - 3-5 个常见问题及解答

7. 贡献指南
   - 如何提交 Issue
   - 如何贡献代码

8. 许可证
   - Apache 2.0
```

### 技术细节

- 语言：中文
- 格式：Markdown
- 截图：使用占位符 `![截图](docs/images/xxx.png)`，后续补充真实截图
- Docker Compose：需要创建 `docker-compose.yml` 文件

### 产物清单

1. `README.md` — 主文档
2. `docker-compose.yml` — Docker 部署配置
3. `docs/images/` — 截图目录（占位）

## 验证标准

- README 内容完整，结构清晰
- Docker Compose 配置可正常启动项目
- 截图占位符路径正确
