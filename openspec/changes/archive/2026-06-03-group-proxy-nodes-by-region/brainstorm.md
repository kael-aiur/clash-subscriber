# Brainstorm: 按地区分组展示代理节点

## 背景

订阅源详情页面的代理节点标签页当前以平铺表格展示所有节点（名称、类型、服务器、端口）。当节点数量多时（数十到上百个），逐条浏览非常混乱。用户希望按地区分组展示，并且与规则标签页一样支持点击展开/折叠。

## 现状分析

- **代理节点展示**：`SubscriptionView.vue` 第 538-546 行，使用 `el-table` 平铺展示
- **规则展示模式**：已实现双层分组（策略 → 规则类型），使用 `el-collapse` + `el-collapse-item`，支持展开/折叠
- **节点命名规范**：大部分节点名称包含国旗 emoji（🇭🇰 香港 | 00），为按地区分组提供了基础

## 决策链

### Q1: 分组层级
**决策**：单层分组，仅按地区分组。
**理由**：用户需求是"按地区分组"，双层（地区 → 类型）增加复杂度但无明显收益。

### Q2: 地区识别策略
**决策**：国旗 emoji 解析 + 预设映射表。
**理由**：国旗 emoji 是最可靠的地区标识，映射表确保所有常见国旗都能正确显示中文地区名。

### Q3: 无地区标识节点处理
**决策**：归入"其他"分组。
**理由**：不丢失任何节点，用户仍可在"其他"中找到未标识地区的节点。

### Q4: 组内展示形式
**决策**：保持表格展示（名称、类型、服务器、端口）。
**理由**：与当前体验一致，用户已熟悉表格列的含义。

## 设计方案

### 方案选择：前端分组 + 国旗映射表（方案三）

**理由**：地区分组本质是展示层优化，纯前端处理最简洁。映射表成本低但覆盖更全面。

### 国旗 emoji → 地区映射表

在前端维护映射对象，覆盖约 20-30 个常见国旗 emoji 到中文地区名的映射：

```
🇭🇰 → 香港    🇯🇵 → 日本    🇺🇸 → 美国    🇸🇬 → 新加坡
🇰🇷 → 韩国    🇬🇧 → 英国    🇩🇪 → 德国    🇫🇷 → 法国
🇦🇺 → 澳大利亚  🇨🇦 → 加拿大   🇮🇳 → 印度    🇹🇼 → 台湾
...
```

### 分组算法

1. 遍历 `detailData.proxies` 数组
2. 对每个节点名称，用正则匹配开头的国旗 emoji
3. 匹配到 → 归入对应地区组；未匹配到 → 归入"其他"组
4. 每组内节点保持原始顺序
5. 各地区组按节点数量降序排列，"其他"组排在最后

### 数据结构

```typescript
interface RegionGroup {
  region: string       // 地区名（如"香港"）
  flag: string         // 国旗 emoji（如"🇭🇰"）
  nodes: ProxyNode[]   // 该地区下的节点列表
  count: number        // 节点数量
}
```

### UI 交互

- **整体结构**：`el-collapse` 包裹所有地区分组，每个分组是 `el-collapse-item`
- **分组头部**：国旗 emoji + 地区名 + 节点数量 tag
- **分组内容**：复用当前 `el-table`（名称、类型、服务器、端口）
- **搜索框**：标签页顶部添加搜索框，支持按节点名称实时过滤，空组自动隐藏
- **默认状态**：全部折叠

### 实现范围

仅修改 `SubscriptionView.vue` 一个文件：
- 新增：国旗 emoji → 地区映射表常量
- 新增：`regionGroups` computed 属性
- 新增：搜索关键词 ref 和过滤逻辑
- 修改：代理节点 tab 模板（el-table → el-collapse + el-table）

### 边缘情况

- 节点名称为空或异常 → 归入"其他"组
- 搜索无结果 → 显示空状态提示
- 代理节点列表为空 → 隐藏分组，显示空表格
